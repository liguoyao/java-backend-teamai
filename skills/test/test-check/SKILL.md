# 验证 Java 变更

1. 查看 `pom.xml`、变更文件和现有测试，确定受影响的模块和测试类。
2. 从 Maven Wrapper 所在目录执行测试。运行单个测试类时，在 Windows 使用 `./mvnw.cmd -Dtest=测试类名 test`，在其他系统使用 `./mvnw -Dtest=测试类名 test`。根据仓库约定添加所需参数。若无法确定影响范围，运行相关模块的测试套件。
3. 报告实际执行的命令和测试结果。若测试失败，记录失败用例和错误摘要。若命令未能启动或没有执行测试，说明具体原因。
